# 1. Introduction — AirWise（Refactored）

> **AirWise: A Data-Grounded and Rule-Governed AI Agent for Personalized Air-Quality Activity Guidance**  
> 版本：2026-11-12｜依據團隊 Proposal v1.1 第 1 節及 `DESIGN.md` 重構。文內 `[n]` 對應原 Proposal 的 References；**引文原始來源尚待提交前逐筆核查**。以下所有「預期」成果均屬研究計畫，並非完成的實驗結果。

## A. Attention Getter — Why Does This Problem Matter?

空氣污染仍是重要的環境健康風險。依團隊提案引用的 *State of Global Air 2025*，2023 年全球約有 790 萬人死亡與空氣污染相關，凸顯空氣污染的健康負擔不只屬於環境監測議題，也涉及日常生活中的行為決策 [1]。臺灣提案引用的 2025 年全國 PM2.5 年平均濃度為 12.6 μg/m³，雖較 2019 年改善，但污染程度仍受地點、季節、天候與時段影響 [2]。因此，全國或全年的平均改善，不能直接回答一位家長明天早上是否適合帶孩子外出活動。

在真實情境中，「AQI 112」是一筆環境指標，卻不是足以直接行動的建議。假設一名有氣喘的孩子準備明早七點跑步三十分鐘，家長需要知道的是**目標時段的風險、個人敏感度、活動強度，以及可以採取什麼替代安排**。將公共環境數據轉譯成具體、可追溯又不過度保證的行動資訊，便是 AirWise 的研究動機。

## B. Background — Environmental Health Meets Domain AI Agents

環境部提供測站空氣品質資訊與 AQI 健康影響及活動建議 [4][15]，中央氣象署提供地方天氣預報 [5]。這些資料支援掌握污染現況與未來變化，但一般使用者仍需自行比對 AQI 等級、健康族群差異、戶外活動強度及天氣趨勢。另一方面，具備 Function Calling 的 LLM 可以理解自然語言並協調外部工具，讓使用者不必自行查找多個網站。

然而，LLM 能流暢生成文字，不代表它能獨立計算可信的 AQI 預測或嚴謹套用健康指引。AirWise 採取 **Domain AI Agent** 定位：由 Planner 解析使用者意圖，從資料與分析模組取得依據，再由規則引擎形成決策，最後僅讓 LLM 負責解釋。這項設計刻意區分「語言生成」與「可查核的領域決策」。

## C. Problem Statement — From Monitoring to Actionable Guidance

本研究欲解決的問題可表述為：**對於具有不同敏感度的臺灣使用者，如何針對指定地點、未來時段與活動強度，整合空氣品質資料、短期預測、官方健康建議與可追溯證據，產生可解釋的活動規劃建議？**

此問題同時涉及五個子需求：（1）正確擷取地點、時段、活動與族群；（2）取得具時間戳記與測站資訊的可靠空品資料；（3）估計未來 1–24 小時 AQI 與不確定性；（4）以臺灣官方 AQI 規則支援健康活動判斷；（5）當資料缺漏或引用不可靠時，採取可預期的保守處置。

主要研究問題（Research Questions）如下：

- **RQ1 — Prediction：** 在不同預測時距（1、6、12、24 小時）下，整合天氣特徵的 XGBoost 能否優於 Persistence 與前日同期基準？
- **RQ2 — Grounding：** 將健康指引由規則引擎明確套用、並限制 LLM 只使用證據輸出，能否提升建議與官方指引的一致率、減少未經證實的數值？
- **RQ3 — Usability：** 相較只顯示 AQI 的既有 App 畫面，AirWise 的情境化建議是否提高使用者主觀理解度與決策信心？

## D. Existing Limitations — What Is Missing Today?

**第一，監測與決策之間存在語意落差。** 傳統空品介面展示數值、顏色與污染物，未必回答使用者應如何調整特定戶外活動。使用者可能知道「橘色」代表什麼顏色，卻仍不知道敏感族群應降低何種活動強度。

**第二，現況查詢不足以支援事前規劃。** 家長、教師與運動者常要決定數小時後的安排，現場即時 AQI 並不等於未來的空氣品質。時間序列預測研究可以改善這一點，但模型誤差、預測區間及跨等級風險必須被納入後續建議。

**第三，族群與暴露情境差異容易被忽略。** 同一 AQI 對健康成人、孩童、長者與心肺疾病患者可能有不同意義；活動的強度和持續時間也會影響暴露。官方指引提供一般性分級，但要轉為個別活動規劃仍需要結構化情境輸入 [15][16]。

**第四，生成式 AI 存在缺乏證據的建議風險。** 既有 LLM 空品介面可改善詢問便利性，但若由模型自行產生 AQI 等級、污染物數據或健康決策，容易出現來源不明或與指引不一致的輸出。相關文獻呈現了即時感測介面、提示設計與 RAG 的價值 [7][10][11]，但不能由此推論已有完整解決個人化活動決策。

## E. Innovation — Proposed AirWise Approach

AirWise 擬以**可追溯的、規則治理的 LLM Agent**整合以下元件：

1. **情境理解與主動澄清：** Planner 從自然語言辨識地點、時間、活動與強度；對必要資訊不足的問題進行反問。
2. **資料與預測整合：** 將環境部測站資料、氣象署天氣預報及歷史資料匯入短期預測引擎；提供 AQI 預測值與區間，而非把單一估計當作確定事實。
3. **Rule-grounded Recommendation：** 依 AQI 六級、族群與活動強度查詢 YAML 規則，保留規則 ID 與官方來源；對敏感族群，於預測區間跨越較高 AQI 等級時採取規劃中的預防原則。
4. **建議與證據分離：** 規則引擎與決策模組先產生可驗證的建議，再由 LLM 依固定證據集合進行語言化；引用驗證失敗時回退至模板回答。
5. **保留活動效益的替代方案：** 以更適合的時段、降低活動強度或改為室內作為選項，避免無條件把「禁止外出」當成唯一建議；這反映活動效益與污染暴露之間的權衡 [17]。

**本專題的創新性不是提出全新的 AQI 指標或 LLM 基礎模型，而是提出一套可測量、可追溯、以臺灣健康指引為核心的整合式個人化決策流程。**

## F. Expected Contributions — Academic and Practical Value

本研究預期產生以下貢獻，並透過 E1–E3 實驗檢驗：

1. **系統方法貢獻：** 設計八模組 Domain AI Agent，明確定義 Planner、資料取得、預測、領域規則、決策與輸出的責任邊界，並提供可重現的需求與測試情境。
2. **領域知識工程貢獻：** 將臺灣官方 AQI 分級、族群差異及活動情境轉為具來源與規則 ID 的可查核規則庫，便於更新與稽核。
3. **預測與決策整合貢獻：** 在預測的不確定性與活動風險之間建立明確的決策連結，觀察區間跨等級時保守處理的影響。
4. **評估方法貢獻：** 建立 50 題臺灣情境問答集，並比較純 LLM、LLM 加即時資料及 AirWise 的一致率、幻覺率、引用正確率及反問表現；搭配預測模型與問卷評估。
5. **實務貢獻：** 預期使使用者從「讀懂 AQI」進一步走向「理解何時、何地、以何種方式活動」，同時保留官方來源、適用限制與免責說明。

**成果界線：** 原提案尚未提供 E1–E3 實測數據，因此不能斷言 AirWise 已優於 Baseline、降低幻覺或提高使用者信心。線上問卷也僅能反映受試者對展示內容的初步偏好，不能等同真實世界健康成效。
